Help us find Arpan, Bhavin and Karan

Arpan Mithalal Kothari (40), Karan Bhardwaj (40), and Bhavinkumar Rajnikant Raval (41) have been missing since the Aug 26, 2026 Nepal-Tibet flash floods near the Rasuwagadhi border crossing, Rasuwa district, Nepal, along with the rest of their Kailash Journeys tour group.

This site is a live, interactive hub with photos, a map of the last known location, continuously updated news feeds (general disaster updates and group-specific updates), a status registry, local resources (hospitals, shelters, survivor leads), and a form to submit any information. It requires JavaScript to display that content — please visit https://findingarpan.vercel.app/ directly in a browser to see it.

If you have any information, however small: use the "Submit Information" form on the site, or call/text +1 (408) 780-8343 or +1 (657) 522-1011.
